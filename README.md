# Womo-Wetter – Sonnen-Radar

Zeigt GAFOR-ähnlich, in welchen Regionen (DE, NL, BE, LU, grenznahes FR) jetzt, in +2 h, +4 h und +6 h die Sonne scheint – für spontane Wohnmobil-Wochenendtouren.
